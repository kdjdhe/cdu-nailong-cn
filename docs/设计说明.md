# 成都奶龙大学.cn —— 奶龙引渡处（着陆页）

访问 `成都奶龙大学.cn` 先过一段奶龙开屏动画，然后**推开龙门**看到"引渡凭证"，
由**用户点击**进入成都大学官网（`www.cdu.edu.cn`）。不自动跳转。

## 文件

| 文件 | 用途 |
|---|---|
| `prototype/index.html` | 独立原型，双击即可预览（加 `?hold=1` 可禁用 60s 兜底跳转，便于长时间检查） |
| `prototype/assets/` | 馆藏画作 webp（4 幅）+ 头像（中心 1 + 环绕 12）+ 门面肌理 |
| `build-worker.mjs` | 构建脚本：改完原型后运行 `node build-worker.mjs` 生成 dist/ |
| `dist/` | 部署目录（`_worker.js` + `wrangler.toml` + `public/assets/`） |

## 页面结构（三段）

**第一幕 · 勋章开屏**（sticky，视差淡出）
- Art-deco 金色勋章，**中心为本尊托腮像**（`wallpaper-main/emotes/奶蛙-表情-03.jpeg` 圆形裁剪），
  环绕 12 颗表情头像（吐舌比心/露齿大笑/微愠/挥手/疑惑/气鼓鼓等，同样出自 emotes 目录）
- 背景四幅馆藏画作轮播（星夜/冲浪/向日葵/呐喊奶蛙），压暗虚化为肌理
- 3 秒引渡倒计时（结束显示"龙"字待命）+「立即前往 ↗」金按钮

**龙门 · scroll-linked 开合**（与第二幕同层重叠）
- 两扇 3D 金门（铜钉浮雕 + 奶龙剪影肌理 + 中央「龙门」金匾）
- 滚动 1:1 驱动开合（ease-out，最大 74°，向屏幕内推门），门缝金光
- **门开一半即可读到后面的凭证**；85% 进度后门层渐隐，100% 完全让位
- 只动 transform/opacity，GPU 合成，全程跟手无延迟

**第二幕 · 引渡凭证**（门后即它，纸张卡片）
- 公函排版 + 馆藏选三联画框（星夜/冲浪/呐喊奶蛙）+「持此凭证 · 即刻启程 ↗」+ 红印
- 页脚：免责声明 + 画作出处署名

## 素材与授权

- **头像/表情**：`wallpaper-main/emotes/`（俏表情网合集，奶龙形象版权归版权方，
  粉丝向非商用；页脚已署名"非官方网站"）
- **馆藏画作**：`奶蛙博物馆素材/01-exhibits/`（奶蛙馆长作品，README 限定个人欣赏，
  公开传播需原作者许可——**正式公开前建议先联系作者**）
- 不使用成都大学校徽、官方 VI。

## 工程要点

- 动画全部 JS 驱动（rAF + 160ms setInterval 双轨，幂等写入），不依赖 CSS 文档时间轴
  （部分环境 CSS animation 的 currentTime 不推进，元素会永远 opacity:0）
- 门开合只写 `transform: rotateY()`，配合 `will-change` 与 `backface-visibility:hidden`
- `?hold=1` 查询参数禁用 meta refresh 兜底（测试用）
- CSP `img-src` 放行本站 punycode 域名 + data: + blob:

## 部署

```bash
node build-worker.mjs          # 重新生成 dist/
cd dist && npx wrangler deploy # 需要该 zone 的 API token（见下）
```

令牌权限：`Zone:Read` + `DNS:Edit` + `Workers Scripts:Edit`（限定该 zone）。
部署后在 Dashboard 给 Worker 绑 Custom Domain：`成都奶龙大学.cn` + `www.成都奶龙大学.cn`。

## 已验证（2026-10-15）

- 龙门四段（25%/60%/90%/100%）滚动表现：门后即凭证、金匾随层渐隐
- 桌面 1440×900 与移动 390×844 两幕布局无重叠
- 「立即前往」/「即刻启程」均白闪后 `location.replace()` 跳官网；60s meta refresh 兜底
- dist 构建产物含全部 18 个 webp 资产；Worker fetch 逻辑 mock 验证通过
